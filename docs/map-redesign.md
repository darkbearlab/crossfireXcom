# 場景重設計（2026-11-23 提案，第一到三階段已做）

## 現在的問題
- 任務名稱都是城市裡的地點，但地圖外觀跟名稱無關：
  - 設施：夜市後巷、舊車站、碼頭倉庫、地下停車場……（`campaign.js` 的 `SITES`）
  - 成員據點：賭場金庫、狗場、舊劇場……（`girls.js` 的 `FACILITIES`）
  - 莊園
- 地圖外觀是從四個野戰主題隨機抽一個（`config.js` 的 `THEMES`：城市廢墟、林地、沙漠前哨、雪原基地）。實測過「夜市後巷」抽到了「雪原基地」。
- 地圖生成（`map.js`）也是野戰的寫法：
  - 隨機擺幾棟方形建築，再隨機撒柱子、成排的箱子、幾團草叢。
  - 不管在哪裡，都是同一種空地加障礙物，看不出是巷子、車站還是倉庫。
- 角色已經換成方塊人，但掩體還是灰色方塊、圓錐樹，風格不一致。

## 目標
1. 看地圖就知道是哪裡：夜市後巷有攤位、燈籠和窄巷；舊車站有月台、鐵軌和候車亭；碼頭倉庫有貨櫃和吊車。
2. 跟方塊人同一種風格：道具都用方塊堆，用夜晚的燈光營造氣氛。
3. 遊戲規則不變：格子還是只有「空地／半掩體／全掩體／隱蔽區」四種，地圖生成現有的限制都保留：
   - 責任區、部署帶在左邊。
   - 長直線不超過 8 格。
   - 敵人崗哨、打手藏身、巢穴的擺法。
   改的是格子怎麼排、長什麼樣子。

## 做法：地點 → 場景組（site kit）
新增 `src/sites.js`，每個地點對應一個場景組，內容是：

| 欄位 | 內容 |
|---|---|
| `layout` | 用哪一種格局產生器（見下表） |
| `full` / `half` | 全掩體、半掩體可以長成哪些道具。依位置挑：貼著邊、連成一排的當牆或建築，單獨一格的當柱子或貨櫃 |
| `conceal` | 隱蔽區叫什麼、長什麼樣子（帆布陰影、貨櫃縫、壞掉的燈下） |
| `floor` | 地面材質和裝飾：柏油、磁磚、石板、草皮；停車格線、鐵軌、水漥 |
| `lights` | 燈光：路燈、燈籠、霓虹招牌、探照燈。手機上限制光源數量，多用發光材質加地上的假光暈 |
| `backdrop` | 地圖邊界外的景：建築立面、圍牆、天際線，不讓地圖浮在一片空地上 |

### 五種格局

| 格局 | 地點 | 樣子 |
|---|---|---|
| **街巷** | 夜市後巷、老舊公寓、洗錢洗衣店 | 上下兩邊是連排建築（全掩體），中間窄巷和小廣場；攤位、機車、垃圾桶當半掩體 |
| **場站** | 碼頭倉庫、貨運站、舊車站、廢車場、狗場 | 貨櫃或車廂一排一排（全掩體），中間有走道；棧板、木箱當半掩體。車站有月台邊緣（半掩體）和鐵軌 |
| **大廳柱網** | 地下停車場、賭場金庫、地下拳場、舊劇場 | 規則的柱子（全掩體）；車子、賭桌、座椅當半掩體；燈壞掉的暗區當隱蔽 |
| **室內房間** | 商業大樓、電話交換所、魔藥工坊、香水工坊、地下藥局、詛咒娃娃工廠、廢棄工廠、武器倉庫 | 房間加走廊，牆上有門；辦公桌、貨架、機器當半掩體。屋頂不畫，用切面的方式看進去 |
| **戶外庭園** | 望遠鏡塔、黑彌撒教堂、莊園 | 樹籬、石牆（全掩體），墓碑、噴水池、花圃（半掩體），高草當隱蔽 |

- 名稱對應：設施用自己的名稱；成員的據點用她的 `FACILITIES`；莊園和決戰用莊園；物資作戰和阻止反制從城市的地點裡抽一個。
- 存檔：`packGen` 現在存的是主題編號，要改成存場景組 id。舊存檔讀不到的話，就退回「城市廢墟」的外觀。
- 四個野戰主題：先留給無盡模式用，或之後再決定要不要拿掉。

## 分階段

| 階段 | 內容 | 會不會影響平衡 |
|---|---|---|
| 1 | 名稱對應到場景組；只換外觀（道具模型、地面、顏色、燈光、邊界外的景），格子還是現在的產生器排的 | 不會 |
| 2 | 五種格局產生器，先做街巷、場站、大廳柱網 | 會：掩體密度、視線、路線都會變 |
| 3 | 室內房間、戶外庭園兩種格局；夜晚燈光細修；手機效能檢查 | 會 |
| 4 | 劇情演出（`scene.js`）的背景改用同一套場景組，不再用畫出來的 `city`、`warehouse` 圖 | 不會 |

階段 2、3 會改到平衡，每種格局都要量同一組數字，和現在的地圖比較：
- 生成成功率和時間
- 全掩體、半掩體、隱蔽格的比例
- 從部署區看得到的崗哨數
- 打手被部署區看到的比例（現在是 0/49）
- 長直線檢查

數字差太多就調格局參數。實際打起來的平衡還是交給你測。

## 決定（2026-11-23）
1. 有時候白天：每個場景組有白天的機率（`day`），室內不分白天晚上。
2. 道具用像素貼圖：程式畫的 16×16 貼圖（`src/pixtex.js`），放大不模糊。
3. 野戰主題留著備用：包成 `field0`～`field3` 場景組，舊存檔讀進來時使用。
4. 可以有特色機關：還沒做，見下面「還沒做的」。

## 做好的（第一到三階段一起做了）
- `src/sites.js`：16 個場景組，23 個地點名稱的對應表，`siteFor(op)` 決定地點和白天晚上。
- `src/layouts.js`：六種格局（field 原本的、street、yard、hall、interior、garden），每個掩體都標上 tag。
- `src/props.js`：照 tag 蓋方塊模型（40 多種）、三種地面、隱蔽區的樣子、地圖外的景、燈光（晚上最多 6 盞點光源）。
- `src/map.js`：地圖多了 `tag`、`floor` 兩層；`tryGenerate` 的格局那一段改成呼叫 layouts.js，其他（部署區、任務、斷長直線、敵人擺放）沒動。
- `src/main.js`：`startMission` 先決定地點再生成地圖；存檔存 `site`，舊存檔用野戰場景組；楓炸出來的半掩體是瓦礫。
- 畫面上方顯示「夜市後巷｜夜晚」，據點和莊園寫出地點：「眼線・薇歐拉的據點｜望遠鏡塔・白天」。

## 還沒做的
- **特色機關**：例如舊車站定時有列車開過鐵軌、碼頭的吊車貨櫃可以打下來、停車場的車子可以引爆、教堂的燭台熄滅會讓視野變短。這些會改到規則，做之前想先跟你確認要哪幾個。
- **劇情演出的背景**（第四階段）：`scene.js` 的文字冒險背景還是畫出來的 `city`、`hq`、`warehouse`，還沒改用場景組。
- 招牌上的字現在是隨機方塊；想要真的字可以用 gpt-image 產幾張招牌貼圖。
