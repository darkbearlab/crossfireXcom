# 劇情演出（2026-11-22 提案，已做出第一版）

程式在 `src/scene.js`。三種畫面共用同一種台詞資料，標題畫面的「劇情演出預覽」可以三種都看一遍（文字介面：`scene vn|battle|radio|all`）。

## 三種畫面

| 畫面 | 用在哪裡 | 會不會擋住遊戲 |
|---|---|---|
| **文字冒險**（`Scene.vn`） | 作戰室、任務前後、章節劇情。背景可以是自訂圖片，或程式畫的背景（`city` 夜晚街道、`hq` 作戰室、`warehouse` 碼頭倉庫）。立繪站在左／中／右，說話的人亮起來 | 會。點畫面或按 Space／Enter 下一句 |
| **戰鬥畫面當背景**（`Scene.battle`） | 戰鬥中的對話：家族成員現身、頭目換段、關鍵時刻。上下出現黑邊，戰場留在中間；操作介面淡出；對話框左邊是胸像；鏡頭轉向說話的人 | 會 |
| **無線電**（`Scene.radio`） | 戰鬥中的短句：開場、被發現、打手衝過來。左上角滑出小框，頭像加掃描線，播完自己收起來 | 不會。可以照常操作；點一下框跳下一句 |

共通：
- 打字機效果：點一下先把這句顯示完，再點一下才下一句。
- 「自動」：自己往下播。「跳過」（或 Esc）：整段跳過。
- 台詞同時記到戰鬥紀錄。
- 文字介面（`?text`、`fast on`）不演出，只記台詞，不會卡住代理試玩。
- 手機直向：對話框貼底、全寬，立繪縮小；無線電框寬度不超過螢幕。

## 頭像和立繪
- 直接用遊戲裡的 3D 模型渲染：胸像（256×256）、全身立繪（360×720），四分之三側面，渲染一次就快取。
- 想換成畫好的圖：說話的人給 `{ name, color, img: 'url' }` 就用圖片（之後可以替換成正式立繪）。
- 太暗的名牌顏色（頭目多半是深色）會自動調亮。

## 台詞格式
```js
Scene.vn([
  { bg: 'hq' },                                   // 換背景：'city' | 'hq' | 'warehouse' | 圖片網址
  { who: 'akane', text: '……', at: 'left' },      // 少女 id
  { who: 'b_book', text: '……', at: 'right' },    // 敵人種類（頭目、槍手……）或家族成員 id（'book'）
  { who: { name: '指揮官', color: 0x8fd3ff, img: 'img/boss.png' }, text: '……' },
  { exit: 'akane' },                              // 立繪退場
  { wait: 500 },
], { bg: 'city' });
```

## 目前接上的地方
- **任務開始**：
  - 家族成員現身或頭目戰：用戰鬥畫面演一段，成員講她的台詞，第一名少女回一句。
  - 其他任務：隨機一名少女用無線電講一句開場。
- **被發現**（第一次警報）：無線電。
- **打手醒來衝過來**：無線電。

## 之後可以加
- 作戰室的章節劇情改用文字冒險畫面，取代現在的文字框（`HQ.showStory`）。
- 頭目換段、成員被擊退時，用戰鬥畫面演一段。
- 正式的立繪、背景圖（用 `img` 和背景網址替換）。
- 台詞表獨立成一個檔案（目前少女的無線電台詞寫在 `main.js` 的 `GIRL_TALK`）。
