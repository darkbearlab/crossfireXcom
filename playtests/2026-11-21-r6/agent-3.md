3. **#3**：千夏標記瑪格麗特，4 骰 90% 中 4 → **瑪格麗特第 1 段破**。千夏殺槍手 f。換彈交出 → 敵人亂了陣腳。
4. **#5**：pass → **瑪格麗特又翻越進來**，被雪乃的反應射擊打中 1（受阻）。
5. **#7**：雪乃（瞄準鏡、沒移動）4 骰 47% 中 3，朱音 3 骰 42% 中 3（護盾擋 2）→ **第 2 段破**。
6. 換彈 pass → **瑪格麗特第三次翻越進來**，吃朱音反應中 2（壓制）。
7. **#9**：雪乃中 1，朱音中 2 → **打倒瑪格麗特，破關**。

瑪格麗特全場沒開過一槍。卡蜜拉被打破一段後就沒再出來。

**整體打法總結**：

1. 開場千夏不移動、先標記再狙擊，清掉高威脅目標。
2. 朱音用雙槍齊射收尾。
3. 換彈或 pass 交出主動權，讓頭目和人偶自己走進三人的反應射擊網。
4. 頭目被壓制後，用突進（必中＋擊退撞牆）或近距離齊射收掉一段。

## Bug／疑似 bug

1. **頭目 AI 會一直走進反應射擊範圍**。四場頭目戰全部發生，嚴重到可以當成穩定戰術：蕾貝卡 3 次、桃樂絲 1 次、瑪格麗特 3 次，都是頭目「翻越掩體」主動走進我方視野、吃反應射擊。
   - 重現：據點戰清掉看得到的手下後，我方換彈或 `pass`。頭目看不到少女時就會移動找射擊角度，而且不避開有反應射擊的少女。
   - README 寫「看不到少女時她會移動去找射擊角度」是設計行為，但結果是頭目變成送分。
2. **「千里眼」同名混淆**。打倒薇歐拉時跳出「「千里眼」失效」（成員加持），但反制卡也叫「千里眼」，結算畫面仍列在「已生效」。玩家會以為反制卡也被取消了。建議其中一個改名（例如反制卡改「警哨」）。
3. **被壓制的敵人「亂了陣腳」後主動權馬上回來**。我方失敗交出主動權後，如果敵方第一個要行動的人被壓制（啟動 45% 以下），常立刻亂了陣腳，主動權回到我方。
   - T1 連續 3 次、T10 兩次、T22 兩次，失敗形同沒有代價。
   - 衝動只讓沒行動的敵人照衝動動一下。有時會開幾槍（T3 一次吃 3 槍），但多數時候什麼都沒發生。
4. **移動預覽的風險只算看得到的敵人**。照 README 這是設計，但文字介面的 `moves` 和 `magic` 對未察覺敵人的發現點完全沒有提示（畫面上有黃圈，文字介面沒有）。代理或玩家常在「風險 0%」的路線被看不到的槍手打中（T6、T10、T21）。建議 `moves` 加一欄「會被發現」。
5. **作戰室敵人數和實際對不上**。作戰室寫「難度 2（敵人 6）／敵人約 6」，成員現身的場次實際是 7（多算頭目）。難度 6 寫約 8，實際是 9。可能沒把現身的成員或條件增援算進去。
6. **文字介面**：
   - `deploy` 擺到非部署格時看起來沒報錯（T5 朱音、T7 光沒擺到指定位置）。
   - 光的狀態列有「（她自己的行動失敗時會自動變身）」，含「失敗」字樣，用字串判斷失敗的腳本會誤判。不算遊戲 bug，但值得注意。
7. **小桃霰彈後座力把自己推出甜蜜距離**：開第一槍後被擊退 1 格，第二槍就從 5 骰掉到 2 骰。這是設計，但連開時體感很差。

### 三人小隊

- **比兩人好玩**：交火有分工，換彈、纏住、壓制時有人補位。
- **但更簡單**：三個人的反應射擊網加上「交出主動權讓敵人走過來」，讓守株待兔成了最強打法。敵人每圖 +1 完全抵不過多一名少女。
- 雙槍齊射、標記擴散、壓制火網這類「一次影響多目標」的能力，在三人隊伍裡疊得太好。

### 五人名單輪替（後送、休整）

- **沒有意義**：23 場沒有任何人倒下，休整 0 次、後送 0 次。
- 輪替只是為了分獎章，而沒出擊的人每場也拿 0.5 枚，所以全員都在 T15～T18 點滿成長樹。
- 「受傷要輪替」這條壓力完全不存在。

- **瞄準鏡**：最強，有三把（千夏、光、雪乃）。沒移動 +15% 對「三下才倒」的系統影響非常大。

- **閃光彈、穿甲彈**：從沒用到，因為瞄準鏡＋雙槍齊射已經夠了。

## 平衡建議（具體數值）

1. **家族威脅成長太慢、太容易擋**。
   - 前 14 回合我擋了 4 張反制，威脅一直是 0；阻止作戰幾乎每回合都在選單上，倒數 6～9 回合完全來得及。
   - 建議：
     - 阻止作戰改成「延後 4 回合」而不是取消，或出現機率降到 1/3。
     - 或難度公式加上時間項：`難度 = 2 + 威脅×2 + floor(回合/5)`。
2. **頭目 AI 不要自殺式走位**。
   - 頭目移動時排除「會被任何還有反應射擊的少女看到」的格子；如果沒有安全格就原地開槍或丟衝動技。
   - 或者給頭目和朱音一樣的被動：「每個敵方主動權第一次被反應射擊必定落空」。
3. **千夏下修**：
   - 瞄準鏡在狙擊步槍上 +15% → **+10%**。
   - 標記魔法樹 4 的 +15% → **+10%**。
   - 槍法 4「打被標記的敵人 +1 骰」→ 改成「打被標記的敵人無視全掩體 1 級」。
   - 不動時視野 +3 → **+2**。
4. **瞄準鏡**：通用 +15% → **+10%**；價格 5～8 → **10～12**。
5. **朱音的雙槍齊射**：副目標骰數 **-1**；或副目標不能是頭目。
6. **獎章太多**：
   - 沒出擊的人 0.5 → **0.25**。
   - 打倒成員全員 +1 → 只給出擊的人。
   - 成長樹第 4、5 格改成 **2 枚／3 枚**。
7. **戰利品**：勝利 3 → **2**；或後期加入高價物品（例如「一次性復活」15 戰利品）。目前結束時剩 56 用不完。
8. **被壓制的敵人亂了陣腳**：被壓制的敵人啟動失敗時，應該只算「這個人跳過行動」，主動權不交回我方；或被壓制時的 -15 改成 -5。
9. **三人小隊的敵人加成**：`SQUAD_EXTRA` 1 → **2**；或據點、決戰再 +2 人。據點的頭目射擊上限（2～4 槍）根本沒機會用上，因為頭目多半處於壓制或受阻。
10. **卡蜜拉**：毒霧改成「每個敵方主動權開始時自動丟一次」，不靠衝動觸發；據點戰的迷霧從 3 片加到 5 片。
11. **桃樂絲的人偶站起來的時機**：改到「敵方主動權開始、所有反應射擊結算之後」，或站起來那一下不觸發反應射擊，不然被打倒過的人偶一站起來就又死了。
