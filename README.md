# 雙人小隊戰術（雛形）

Three.js 做的 XCOM 風格回合制戰術遊戲雛形：每場戰鬥只有 2 名士兵，連續打很多張程序生成的小地圖。

## 執行

ES modules 需要用本機伺服器開（直接雙擊 index.html 不行）。用附的開發伺服器（關閉快取，改了程式重新整理就生效）：

```
python serve.py
```

然後打開 http://localhost:8123

## 檔案

| 檔案 | 內容 |
|---|---|
| `src/config.js` | 所有數值：命中、掩體、武器、士兵/敵人屬性與衝動、敵人編組、地圖主題 |
| `src/map.js` | 小地圖程序生成（責任區、建築、掩體、隱蔽區、散佈的崗哨、任務目標、補給箱） |
| `src/grid.js` | 直線移動、視線（含未警戒視線）、掩體判定、命中率公式 |
| `src/units.js` | 單位模型（暫用方塊人） |
| `src/ui.js` | HUD |
| `src/main.js` | 場景、主動權流程、警戒、武器操作、敵人 AI 與衝動、任務迴圈 |

## 目前的規則（主動權制，參考桌上戰棋 Crossfire 的單兵版）

- **沒有回合，只有主動權**：持有主動權的一方可用任意順序、任意次數指揮所有單位，直到某個行動**失敗**才交給對方。也可以主動放棄（Backspace）。
- **失敗**：主動射擊沒造成傷害；移動中被反應射擊命中。
- **移動**：任意角度直線走到任一格，不限距離，路線要淨空（不能穿過掩體或單位）。
- **翻越**：越過相鄰的半掩體是獨立的一次移動（紫色格）。
- **反應射擊**：自動。對方移動時，每個看得到路線的單位最多開一槍，挑命中率最高的點（同分取離起點近的）。命中率低於 `REACTION_MIN` 不開。
  反應射擊打空 → 該單位這次主動權內不能再開槍（✕）。
- **壓制**（▼）：被命中的單位開槍 -20、被打 -20、不能移動。花一個行動解除，目前必定成功。被壓制時再被命中照樣扣血。
- **命中率** = 命中值 − 掩體（半 20 / 全 40）+ 近距離 10 − 遠距離懲罰；從沒有掩體的方向打 = 側翼，暴擊 +40%。
- **敵人用同一套規則**。我方不會自動對還沒察覺的敵人開反應槍（會暴露位置）。

### 潛入與警戒
- 敵人散佈在地圖各處的崗哨，一開始**未警戒**（標籤前有 `?`）。
- **責任區**：地圖（部署帶以外）切成幾塊，建築室內各自一塊。未警戒的敵人只看自己負責的那一塊（看過的敵人，責任區會以黃色標出）。
- 未警戒視線：只看 5 格（`QUIET_SIGHT`）、看不穿半掩體、看不穿也看不進**隱蔽區**（草叢、瓦礫陰影等）。警戒後照常（10 格、隱蔽區無效）。
- 移動途中被未警戒的敵人看到 → 移動停在那格（不算失敗），他和同責任區的同伴進入警戒。移動預覽會用**黃圈**標出會被發現的位置。
- 開槍會驚動射手與目標周圍 6 格（`NOISE`）內的敵人。警戒是永久的。

### 武器與彈藥
- 我方用特殊武器：較高的命中與傷害，但有彈匣與備彈。**反應射擊也耗彈**。
- **換主武器、主武器換彈** → 做完交出主動權（按鈕橘框，要按兩次確認）。
- **換手槍、手槍換彈**很快，不交出主動權。手槍無限備彈、但不能反應射擊。
- 武器：突擊步槍（平均）、霰彈槍（近距離強）、狙擊步槍（主動射擊無視半掩體、不能反應）、輕機槍（反應射擊打空不停火）。新兵隨機配發。
- **生命與彈藥是戰役資源**：任務之間不會補充，只能靠地圖上的補給箱（彈藥箱 = 主武器兩個彈匣、醫療包 +3 HP），陣亡士兵由滿彈的新兵遞補。

### 敵人個性（衝動）
- 主動權交回我方時，這一輪沒行動過、沒被壓制的敵人會執行自己的**衝動**；未警戒的敵人則在自己的責任區內巡邏。
- 槍手：對最近的可見目標開槍。狂徒：朝最近的我方衝 3 格。徵召兵：軍官不在時往地圖邊緣逃，逃出就消失。
- 軍官（活著時徵召兵不逃）、狙擊手（主動射擊無視半掩體、不反應射擊）、機槍手（笨重：每次主動權只行動一次；反應射擊打空不停火）、重裝兵（裝甲 1）。

### 任務
- **部署階段**：在左側綠色部署區自由擺放兩名士兵，按 Enter 開始。部署帶不屬於任何責任區，敵人崗哨至少離 7 格。
- **突破撤離**：所有存活士兵站上右側撤離點（青色格）。
- **破壞終端**：在終端旁安裝炸藥（一個行動），再撤回左側撤離點。
- 清光敵人也算完成。兩人都陣亡 → 重新開始。
